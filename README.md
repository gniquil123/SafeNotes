# 加密记事本（SafeNotes）

Windows 桌面加密保险库：账号密码、文本笔记、图片统一加密存储。
每次打开必须输入主密码，运行中实时解密展示，关闭 / 锁定后磁盘上只存在密文。

典型场景：密码本 —— 把各个账号的不同密码记录下来，需要时输入主密码解锁查看。

## 快速开始

```bash
pip install -r requirements.txt
python main.py
```

首次运行会弹出启动选择器，之后每次启动都可以选择：**解锁上次使用的保险库**（回车直达）、**打开其他保险库文件**（含 `.bak` 备份）、或**新建保险库**。

打包为单个 exe：

```bash
pip install pyinstaller
build.bat        # 产出 dist\加密记事本.exe
```

## 安全架构

| 环节 | 实现 | 说明 |
|---|---|---|
| 密钥派生 | **Argon2id**（256 MiB / 3 轮 / 4 线程，RFC 9106 高安全方向） | 内存硬化，每次尝试消耗 256MB 内存 + 约 1 秒计算，GPU/ASIC 离线爆破成本极高 |
| 内容加密 | **AES-256-GCM** | 认证加密，机密性 + 完整性一体；每次加密独立随机 96bit nonce |
| 密码校验 | GCM 认证标签 | 头部存「验证器」（随机 32B 用主密钥加密），解密通过 = 密码正确，**无任何口令哈希** |
| 防降级 | 头部整体作 AAD | 篡改 KDF 参数 / 盐 / 版本号都会导致认证失败 |
| 落盘安全 | 原子写（临时文件 + fsync + replace） | 断电 / 崩溃不会产生半截文件 |

这套组合与 KeePass / Bitwarden / 1Password 属同一方案等级，是当前可公开使用的最强实用加密。

### 运行时防护

- **闲置自动锁定**（默认 5 分钟，可设 1~10 分钟或关闭）：锁定即清零内存中的主密钥与明文
- **剪贴板自动清除**（默认 20 秒）：复制密码后到时自动清空（内容未被覆盖时才清）
- **防截屏 / 防录屏**：`SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`，Win+Shift+S、OBS 等截到的窗口区域为黑
- **错误尝试退避**：连续 4~5 次错密码等待 30 秒，≥6 次等待 5 分钟（防随手尝试；防离线爆破靠 Argon2id）
- 锁定时同时清空撤销栈（其中含明文副本）

## 防丢失体系（六层）

1. **文本编辑撤销**：输入框内 Ctrl+Z（Qt 自带）
2. **条目级撤销 / 重做（50 步）**：保存 / 新建 / 删除 / 恢复均可撤销（Ctrl+Z，输入框外）
3. **条目历史版本**：每次保存前旧内容自动快照（默认每条保留 20 版，可设 10/20/50），跨会话持久、加密存储；🕘 对话框可预览并一键恢复任意版本，恢复前再自动快照 —— **存错密码永远能找回**
4. **回收站**：删除先进回收站，可恢复 / 彻底删除（本次会话内 Ctrl+Z 仍可撤销彻底删除）
5. **文件级滚动备份**：每次会话首次保存前自动轮换 `.bak.1` ~ `.bak.5`；修改主密码前强制备份
6. **原子写 + GCM 完整性校验**

## 威胁模型（诚实说明）

**能防御**：设备被盗后他人直接读取文件、云端 / 网盘同步泄露、截屏录屏、剪贴板残留、肩窥随手尝试、软件自身写坏数据。

**不能防御**（无任何软件能完全防御）：

- **主密码被知道**：主密码是唯一钥匙，遗失无法找回（无后门），泄露等于交出全部数据
- **运行中已解锁状态下植入的键盘记录器 / 恶意软件**：内容已在内存中解密
- **内存取证**：Python 运行时无法保证密钥和明文被彻底擦除（bytes 不可变）；锁定后密钥 bytearray 覆写清零是 best-effort
- **弱主密码的离线暴力破解**：Argon2id 使单次尝试极贵，但密码本身过弱（如 6 位数字）仍可能在有限次数内被穷举 —— 请使用 12 位以上强主密码

## 文件格式

```
"SNVAULT1"(8B) | 版本 u16 | Argon2id 参数(t,m,p u32×3) | 盐 32B
| 验证器 nonce12+密文48 | payload nonce12 + AES-256-GCM 密文(JSON)
```

payload 为整个数据库的 JSON：条目（含字段 / 图片 base64 / 历史版本）、设置。
`.bak.1` ~ `.bak.5` 为滚动备份，格式相同，可直接当保险库打开。

```
app/core/models.py         Entry / 历史快照数据模型
app/core/database.py       内存库：CRUD / 搜索 / 回收站 / 历史版本

app/core/commands.py       各业务撤销命令

app/ui/*                   界面（解锁 / 主窗口三栏 / 编辑器 / 历史 / 生成器 / 设置）
app/utils/strength.py      密码强度评估
app/utils/win32.py         防截屏

```

```bash
python -m pytest tests/          # 全部测试
python main.py --smoke           # 无人工介入的 GUI 冒烟（临时库，3 秒自动退出）
```

> 注：`SAFENOTES_LOW_KDF=1` 环境变量将 KDF 降为 8MB/1 轮，仅供测试加速，
> 正常启动始终使用 256MB 全强度参数。

demo.html 为早期浏览器交互演示版，与正式版交互一致，可留作参考或删除。
