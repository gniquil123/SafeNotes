# 加密记事本 — 单 HTML 文件 Demo

做一个**零依赖单文件 `demo.html`**（原生 HTML/CSS/JS，双击即可在浏览器打开），完整演示桌面版的界面、交互和安全模型，验证设计后再开发正式的 PySide6 桌面版。

## Demo 包含的内容

**1. 加密体系（真实实现，非假动画）**
- Web Crypto API：主密码 → PBKDF2-SHA256(600,000 迭代) 派生密钥 → AES-256-GCM 加密全部数据
- 加密后的密文存 localStorage：关闭浏览器重开，必须重新输密码，数据仍在且是密文
- 附带「查看底层存储」小面板：直观展示磁盘上存的只有 base64 密文，无任何明文
- 注：浏览器内用 PBKDF2 近似（正式桌面版用更强的 Argon2id 256MB，demo 中会标注说明）

**2. 完整界面流程（全中文、浅/深主题可切换）**
- 首次启动：创建保险库（设密码×2 + 强度条 + 「密码丢失无法找回」警告）
- 再次打开：锁屏解锁（错误提示 + 连错退避倒计时演示）
- 主窗口三栏：分类侧栏（全部/各分类/回收站/＋新建）｜条目列表｜详情编辑区
- 顶部工具栏：↩撤销 ↪重做 ｜＋密码条目 ＋笔记 ｜🔒手动锁定 ｜ Theme ｜ ⚙设置 ｜ 查看密文

**3. 功能演示**
- 密码条目：标题/分类/账号/密码/网址/备注；密码遮蔽切换、复制（20s 自动清剪贴板演示）、🎲生成器（长度/字符集/排除易混淆）、四级强度条
- 笔记条目：多行文本 + 图片（粘贴/选择，base64 加密存储，demo 限单图 500KB）
- 搜索：标题/账号/备注实时过滤
- **撤销/重做 50 步**（保存/新建/删除均可撤销，Ctrl+Z / Ctrl+Y + 工具栏按钮）
- **历史版本**：每次保存自动快照旧版本（每条保留 20 版），🕘历史版本对话框：版本列表→预览→一键恢复
- **回收站**：软删除→回收站分类→恢复/彻底删除
- 自动锁定演示：闲置 1 分钟（demo 缩短，正式版默认 5 分钟）回锁屏
- 设置：自动锁定时长、剪贴板清除秒数、历史版本保留数

**4. 预置示例数据**（首次创建后自动填充几条示例条目：GitHub 账号、银行卡、服务器笔记等），打开即可体验全部功能，无需手动造数据
