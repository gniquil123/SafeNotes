# SafeNotes (Зашифрованный блокнот)

**Выбор языка / Switch language / 语言切换：**
[中文](README.md) · [English](README.en.md) · [Русский](README.ru.md)

Зашифрованное хранилище для Windows: пароли от учётных записей, текстовые заметки и изображения хранятся в едином зашифрованном виде.
При каждом открытии требуется мастер-пароль; во время работы содержимое расшифровывается и отображается в реальном времени, а после закрытия / блокировки на диске остаётся только шифротекст.

Типичный сценарий: книга паролей — запись паролей от разных учётных записей, при необходимости открываете мастер-паролем и просматриваете.

## Быстрый старт

```bash
pip install -r requirements.txt
python main.py
```

При первом запуске появляется окно выбора хранилища; при каждом последующем запуске можно выбрать: **Открыть последнее хранилище** (Enter — сразу войти), **Открыть другой файл хранилища** (включая резервные копии `.bak`) или **Создать новое хранилище**.

Сборка в один exe:

```bash
pip install pyinstaller
build.bat        # создаёт dist\加密记事本.exe
```

## Архитектура безопасности

| Этап | Реализация | Примечание |
|---|---|---|
| Получение ключа | **Argon2id** (256 МиБ / 3 прохода / 4 потока, направление высокой безопасности RFC 9106) | Устойчиво к перебору в памяти; каждая попытка требует 256 МБ памяти + около 1 с вычислений, что делает офлайн-взлом на GPU/ASIC крайне затратным |
| Шифрование содержимого | **AES-256-GCM** | Аутентифицированное шифрование, сочетает конфиденциальность и целостность; при каждом шифровании используется независимый случайный 96-битный nonce |
| Проверка пароля | Аутентификационный тег GCM | В заголовке хранится «проверяющий блок» (случайные 32 Б, зашифрованные мастер-ключом); успешная расшифровка = правильный пароль, **никакого хеша пароля** |
| Защита от понижения версии | Весь заголовок выступает в роли AAD | Изменение параметров KDF / соли / версии приводит к сбою аутентификации |
| Безопасная запись | Атомарная запись (временный файл + fsync + replace) | При сбое питания / крахе не образуется обрезанный файл |

Эти решения того же уровня, что и KeePass / Bitwarden / 1Password, и относятся к самому сильному практически доступному шифрованию.

### Защита во время работы

- **Автоблокировка при бездействии** (по умолчанию 5 мин, настраивается 1–10 мин или отключение): при блокировке мастер-ключ и открытый текст обнуляются в памяти
- **Автоочистка буфера обмена** (по умолчанию 20 с): после копирования пароля он очищается по истечении таймера (только если содержимое не было перезаписано)
- **Защита от скриншотов / записи экрана**: `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`, поэтому Win+Shift+S, OBS и т. п. захватывают область окна чёрной
- **Задержка после неверных попыток**: при 4–5 неверных паролях подряд ожидание 30 с, при ≥6 — 5 мин (защита от случайных попыток; офлайн-взлом отрабатывает Argon2id)
- При блокировке также очищается стек отмены (в нём есть копии открытого текста)

## Система защиты от потери данных (шесть уровней)

1. **Отмена редактирования текста**: Ctrl+Z внутри поля ввода (встроено в Qt)
2. **Отмена / повтор на уровне записи (50 шагов)**: сохранение / создание / удаление / восстановление можно отменить (Ctrl+Z, вне поля ввода)
3. **История версий записи**: перед каждым сохранением старое содержимое автоматически сохраняется в снимок (по умолчанию 20 версий на запись, настраивается 10/20/50), сохраняется между сеансами и хранится зашифрованным; диалог 🕘 позволяет просмотреть и восстановить любую версию одним кликом, перед восстановлением делается ещё один снимок — **неправильно сохранённый пароль всегда можно вернуть**
4. **Корзина**: удаление сначала попадает в корзину, её можно восстановить или удалить окончательно; (в рамках текущего сеанса Ctrl+Z по-прежнему отменяет окончательное удаление)
5. **Скользящие резервные копии на уровне файлов**: `.bak.1` ~ `.bak.5` автоматически ротируется перед первым сохранением в каждом сеансе; перед сменой мастер-пароля создаётся принудительная копия
6. **Атомарная запись + проверка целостности GCM**

## Модель угроз (честное описание)

**Защищает от**: прямого чтения файла другими лицами после кражи устройства, утечки при синхронизации облака / облачного диска, скриншотов и записи экрана, остатков в буфере обмена, случайных попыток подсмотреть через плечо и порчи данных самим программным обеспечением.

**Не защищает от** (никакое программное обеспечение не защищает полностью):

- **Мастер-пароль стал известен**: мастер-пароль — единственный ключ; при утрате его невозможно вернуть (нет бэкдора), а его утечка означает передачу всех данных
- **Кейлоггеры / вредоносное ПО, установленные во время работы при разблокировке**: содержимое уже расшифровано в памяти
- **Судебная экспертиза памяти**: среда выполнения Python не гарантирует полного стирания ключей и открытого текста (bytes неизменяемы); затирание bytearray ключа при блокировке — это best-effort
- **Офлайн-взлом слабого мастер-пароля**: Argon2id делает каждую попытку очень дорогой, но слишком слабый пароль (например, 6 цифр) всё же можно перебрать за ограниченное число попыток — используйте надёжный мастер-пароль из 12+ символов

## Формат файла

```
"SNVAULT1"(8Б) | версия u16 | параметры Argon2id (t,m,p u32×3) | соль 32Б
| верifier nonce12+шифротекст48 | payload nonce12 + шифротекст AES-256-GCM (JSON)
```

Payload — это JSON всей базы данных: записи (поля / изображения base64 / версии истории) и настройки.
`.bak.1` ~ `.bak.5` — скользящие резервные копии того же формата, их можно открыть напрямую как хранилище.

## Структура проекта и тестирование

```
main.py                    Точка входа (один экземпляр / поток разблокировки / дымовой тест --smoke)
app/crypto/kdf.py          Получение ключа на основе Argon2id
app/crypto/vault.py        Формат файла / атомарная запись / ротация резервных копий / повторное шифрование при смене пароля
app/crypto/secure.py       Хранение и обнуление ключа
app/core/models.py         Модели данных Entry / снимков истории
app/core/database.py       Хранилище в памяти: CRUD / поиск / корзина / версии истории
app/core/undostack.py      Менеджер отмены на 50 шагов
app/core/commands.py       Бизнес-команды отмены
app/core/clipboard.py      Безопасное копирование + очистка по таймеру
app/ui/*                   Интерфейс (разблокировка / главное окно из трёх панелей / редактор / история / генератор / настройки)
app/utils/strength.py      Оценка надёжности пароля
app/utils/win32.py         Защита от скриншотов
tests/                     35 модульных / сквозных тестов
```

```bash
python -m pytest tests/          # Все тесты
python main.py --smoke           # Дымовой GUI-тест без участия человека (временное хранилище, авто-выход через 3 с)
```

> Примечание: переменная окружения `SAFENOTES_LOW_KDF=1` снижает KDF до 8 МБ / 1 проход, только для ускорения тестов;
> при обычном запуске всегда используются полноценные параметры 256 МБ.
